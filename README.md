School Project for CS 320 Class

How can I ensure that my code, program, or software is functional and secure?

  Ensuring that my code is functional and secure is imperative to software design. This can be achieved in many different ways such as ensuring that the code is modular keeping data and permissions from leaking and changing data in unintended ways and implementing proper restrictions to data access. Software testing is crucial to having functional software. All software should be tested to make sure that any and all bugs can be eliminated prior to implementation. If I am able to test all programs I wrtie, Ensuring that they function properly should be simple.

How do I interpret user needs and incorporate them into a program?

 Generally, I take down the list of requirements and keep them as a check list separate from teh project so that I can keep track of the overall progress of the project. This helps me keep all of the relevant points in mind when working on the project. It helps me not miss certain small things in the code which can lead to major bugs later in development, reducing the strain of the project and helping deliver a much better product for the user.

How do I approach designing software?

  I always try to start with a pseudocode base, (even if I don't write it down) and use this to determine the entire scope of the project accounting for all necessary requirements. THis forms a baseline fore how the project will progress and helps me pre-emtively have and idea as to where to go next. This also helps me separate parts of the code into blocks that will eventually for the framework for the modularity of the programs themselves.
